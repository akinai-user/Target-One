URL指定：競合サイトや比較ページの閲覧者に配信

競合HPの特定ページ、比較記事、価格・店舗情報ページなどを指定できます。ドメイン単位だけでなく、2階層目以降の特定ページまで絞り込めます。

指定できるURLの例

種類 例 狙える人
競合のサービスページ 競合の料金ページ、サービス紹介ページ 競合を具体的に検討している人
比較・口コミサイト 比較サイトや口コミサイトの該当ページ 複数の会社を見比べている人
業界メディア 業界ニュースや関連記事 課題を感じて情報を集めている人
店舗・物件情報 競合店舗のページ、物件の詳細ページ 近くで店舗や物件を探している人

意図の強さで絞り込む

同じ競合サイトでも、トップページを見た人と料金ページを見た人では、検討の深さが違います。閲覧したページの種類から意図の強さを判断し、見込みの高い層を優先して配信できます。
